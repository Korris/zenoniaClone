Willowbrook Village - Wooden Bench 3D / RO Soft Adventure

Files: Willowbrook_Bench.obj, Willowbrook_Bench.mtl, Bench_Handpainted_Atlas_1024.png
Approx dimensions: 1.85m W x 0.72m D x 1.00m H; 1 unit = 1 meter, Y up, pivot at ground (0,0,0).
Geometry: 456 triangles, modeled procedurally from wood planks, timber supports, trim and decorative armrests.

Unity import:
1. Unzip files together under Assets/Willowbrook/Props/Bench/
2. Drag OBJ into scene; scale (1,1,1), rotation 0 unless needed.
3. If texture is not assigned, create Material using your Built-in pipeline Standard shader (or Unlit Texture for testing), set Albedo/Base Map to the PNG, metallic 0, smoothness 0.08.
4. The OBJ is static and has no colliders; optionally add BoxCollider sized approx 1.85 x 1.0 x 0.72m and centered near y=0.5.
5. Cast/receive shadows on. Texture is intentionally painted, not photogrammetric.

This is an original modular test asset, NOT a reconstruction of the prior 2D bench sprite.
