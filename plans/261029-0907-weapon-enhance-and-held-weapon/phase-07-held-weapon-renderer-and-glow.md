## Key Insights
- Both atlas and registry are already >200 LOC -> new split modules, 1-2 line hooks in the originals.
- Asset gating per animation: use weaponless sheet only if (sheet loaded AND anchors exist for anim) else baked frame.
  Mixed per-anim rollout is safe because both sets share 192px frames + 8 ppu (feet alignment verified in P5).
- Avoid 404 spam before art lands: atlas lists only anims present in `WEAPONLESS_READY` (generated by P5 tool
  into the anchors module or a small constant) rather than requesting all 8 blindly.
- Perf budget: +1 drawImage per hero (+1 aura layer at +13, + <=5 tiny sparkle paths). Glow baked once per
  (type, variant, band) => max 9*2*4 = 72 small canvases worst case, lazily.
- No shadowBlur, no radial-gradient fog. Glow = crisp dilated silhouette rings (draw tinted silhouette at 12-16
  offsets on a circle radius r, `source-in` tint) — reads as anime outline/aura, not haze.

## Visual bands (art direction: anime, clean, no fog)
| Level | Art | Glow (baked) | Runtime extra |
|---|---|---|---|
| +0..+6 | base | none | - |
| +7..+8 | enhanced | thin pale rim r=2, a=0.55 (glow color mixed 50% white) | - |
| +9..+10 | enhanced | colored edge r=3 a=0.85 + 1px white inner line | - |
| +11..+12 | enhanced | + blade-hugging aura: stepped rings r=5 a=0.4, r=8 a=0.2 | - |
| +13..+15 | enhanced | as +11, aura on separate canvas | aura alpha pulse 0.55..1 (sin, 900ms); 3 (+15: 5) 4-point sparkles along blade axis, deterministic positions, 600ms twinkle |
Glow color = manifest `glow` per type. Radii in source px (art ~256px tall) -> ~0.5-1 world unit on screen.

## Architecture
```
drawPlayer(ctx, player, registry)
  -> pick = heroFramePick(set, player)           // {anim, index}; existing selection logic unchanged
  -> held = resolveHeldWeapon(player, registry, pick)   // null => legacy path (baked frame)
       warrior && HELD_WEAPON_ENABLED && weaponless[dir][anim] && anchors[anim][dir][index] && !hidden
       weapon = player.equipment.weapon (fallback: starter 'sword' +0)
       sprite = bakedWeaponSprite(type, variant(enhance>=7), band)   // weapon-glow-baker cache
  -> draw order: anchor.behind ? [weapon, body] : [body, weapon]; dash ghosts reuse same composite at alpha
  -> band 4: drawEnhanceSparkles(ctx, transform, time)
Transform (held-weapon-anchor-math): translate(frameX + ax*u, frameY + ay*u) rotate(angle)
  scale(worldLen*typeLength*clamp(len/refLen)/spriteH) translate(-gripX, -gripY); u = 24/192 world per px.
```
